# Embedding-Model-Visualizer

A beginner-friendly AI project that converts text sentences into numerical vector representations using a pre-trained Sentence Transformer model and displays the generated embeddings.

## Project Overview

This project demonstrates how text can be converted into numerical vectors using **Sentence Transformers**.

A user provides a set of sentences. The application:

1. Loads the `all-MiniLM-L6-v2` embedding model.
2. Accepts multiple text sentences.
3. Converts each sentence into a numerical embedding.
4. Displays the generated vector values.
5. Displays the number of dimensions in each embedding.
6. Confirms that the text has been successfully converted into numerical vectors.

## Project Flow

Text Input → Sentence Transformer → Text Encoding → Numerical Embedding → Vector Representation

## Model Used

This project uses:

```text
all-MiniLM-L6-v2
```

The model is available through the Sentence Transformers library.

Each sentence is converted into a **384-dimensional numerical vector**.

Therefore:

```text
One Sentence → 384 Numerical Values
```

## Run the Project

Open the terminal inside the project folder and run:

```text

```

The program will load the model and generate embeddings for the input sentences.

## Embedding Process

The project uses the following basic process:

### 1. Text Input

The program receives multiple sentences.

### 2. Model Loading

The `all-MiniLM-L6-v2` model is loaded using:

```python
SentenceTransformer("all-MiniLM-L6-v2")
```

### 3. Encoding

The sentences are passed to the model using:

```python
model.encode(sentences)
```

### 4. Vector Generation

Each sentence is converted into a numerical vector.

### 5. Dimension Checking

The program checks the size of each generated vector.

For this model:

```text
Embedding Dimension = 384
```

## Semantic Representation

Embeddings allow text to be represented according to its learned semantic information.

For example:

```text
"I like eating pizza."

"Pizza is my favorite food."
```

These sentences are related in meaning. Their embedding vectors can therefore be compared using similarity techniques.

## Important Note

This project is an educational demonstration of text embeddings.

The generated numerical values are not individual human-readable meanings. Each vector contains many numerical values that together represent the learned representation of the input sentence.

The project demonstrates how text can be transformed into a format that machine learning systems can process.

## Limitations

* The model may not understand every sentence perfectly.
* Embeddings are numerical representations and are not directly human-readable.
* The project only generates embeddings and does not perform similarity calculation.
* The project does not use a vector database.
* The current implementation works with predefined input sentences.
* The quality of the representation depends on the selected embedding model.

## Embeddings in RAG

Embeddings are an important component of RAG systems.

The basic RAG process is:

```text
Documents
    ↓
Text Chunking
    ↓
Embedding Model
    ↓
Numerical Vectors
    ↓
Vector Database
```

When a user asks a question:

```text
User Query
    ↓
Query Embedding
    ↓
Similarity Search
    ↓
Relevant Documents
    ↓
LLM
    ↓
Final Answer
```

This allows the system to retrieve information based on semantic meaning.
